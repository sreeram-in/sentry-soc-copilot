About this project

Explainable AI-Based SOC Copilot for Network Intrusion Detection and Anomaly Analysis.

What's real here

The live feed is built from real packets captured on a real network interface (via scapy/Npcap) — not generated or replayed. Flows are extracted from those packets using the same 5-tuple grouping approach as tools like CICFlowMeter, then scored the moment they complete. The app's own dashboard traffic is explicitly excluded from capture so it can never detect itself.

Pipeline

  • Real packet capture & flow extraction — scapy, direction-independent 5-tuple flow tracking, 5s idle timeout
  • Supervised classification — {{ backend }}
  • Unsupervised anomaly detection — Isolation Forest, trained on normal traffic only
  • Chat & report narrative — Groq free API, on-demand

Stack

Flask · scapy · scikit-learn · XGBoost · Groq API · vanilla JS · hand-written CSS
